# Статус приёмки рабочей модели

Дата живой проверки: 27.08.2026  
Ветка: `dev/mytgbot-v2`

## Подтверждено пользователем в Telegram

- тестовый бот запускается через временный GitHub Actions стенд;
- владелец из `ADMIN_IDS` авторизуется как инженер-технолог;
- список судов открывается;
- навигация по ремонтной ведомости, разделам и пунктам работает;
- диалог создания акта завершается без ошибки;
- бот формирует и отправляет XLSX по новому утверждённому шаблону.

## Автоматические проверки

- 111 тестов проходят локально;
- проверены роли и защита неавторизованного доступа;
- проверены сессии диалога, генерация XLSX и жизненный цикл документов;
- проверен импорт приложения и регистрация обработчиков.

## Не относится к текущей приёмке

- круглосуточный производственный хостинг;
- постоянная БД между временными GitHub Actions запусками;
- окончательная настройка внешнего AI-провайдера.

Временный стенд используется только для приёмочных сеансов. Значение
`.telegram-smoke-trigger` `action=stop` завершает активный сеанс через механизм
concurrency и не запускает новый Telegram-процесс.
