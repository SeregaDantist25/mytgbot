## 📁 Созданные файлы

### 1. `schemas.py` (280 строк)
Pydantic модели для валидации входных данных:
- `UserRole` — enum ролей
- `UserCreate` — создание пользователя
- `UserUpdate` — обновление пользователя
- `DocumentCreate` — создание документа
- `DocumentUpdate` — обновление документа
- `RepairItemCreate` — создание ремонтного объекта
- `CallbackData` — валидация callback данных
- `MessageData` — валидация текста сообщения
- `PaginationParams` — параметры пагинации
- `SearchParams` — параметры поиска

**Особенности:**
- Валидация типов данных
- Проверка диапазонов значений
- Защита от SQL-инъекций
- Защита от XSS-атак

### 2. `utils/rate_limiter.py` (150 строк)
Класс RateLimiter для защиты от спама:
- `is_allowed(user_id)` — проверка лимита
- `get_retry_after(user_id)` — время до следующего запроса
- `reset(user_id)` — сброс счётчика
- `get_stats(user_id)` — статистика запросов

**Глобальные limiters:**
- `message_limiter` — 30 сообщений/мин
- `file_limiter` — 5 файлов/мин
- `approve_limiter` — 10 утверждений/мин
- `command_limiter` — 20 команд/мин

**Особенности:**
- Потокобезопасен (threading.Lock)
- In-memory хранилище
- Автоматическая очистка старых запросов

### 3. `utils/decorators.py` (280 строк)
Декораторы для обработчиков:
- `@require_role()` — проверка роли пользователя
- `@require_admin()` — проверка администратора
- `@rate_limit()` — ограничение частоты запросов
- `@handle_exceptions()` — обработка исключений
- `@validate_input()` — валидация через Pydantic
- `@log_execution()` — логирование выполнения
- `combine_decorators()` — комбинирование декораторов

**Особенности:**
- Автоматическое логирование
- Отправка сообщений об ошибках пользователю
- Комбинируемость

### 4. `config.py` (180 строк)
Конфигурация и логирование:
- `setup_logging()` — инициализация логирования
- `Config` — dataclass с конфигурацией
- `get_config()` — получение глобальной конфигурации

**Особенности:**
- Ротация файлов логов (10 MB, 5 файлов)
- Логирование в консоль и файл
- Валидация конфигурации
- Поддержка переменных окружения

### 5. `utils/__init__.py` (5 строк)
Экспорт компонентов утилит
